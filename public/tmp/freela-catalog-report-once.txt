- Усі **403** опубліковані інструменти мають `processingMode: LOCAL_ONLY` і `clientOnly: true`.
- **Немає** серверного OCR, PDF→Word/Excel/PowerPoint, хмарного зберігання чи email-доставки.
- **DOCX→PDF** — лише текст через mammoth; без зображень/колонок/шрифтів Word.
- **Extract PDF text** — шар тексту pdf.js; скани без text layer лишаються порожніми (не OCR).
- **Resize / compress image** — canvas API браузера; не AI upscale і не професійний кодек.
- **HEIC** — heic2any; окремі файли можуть не декодуватись у цьому білді.
- **PDF password** і **Convert video** — опубліковані як чесні *deferred* сторінки (шифрування / ffmpeg.wasm не підключені).
- **Compress PDF** — структурне стиснення object streams (pdf-lib), не recompress вкладених JPEG.
